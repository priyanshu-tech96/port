# Priyanshu Singh — React Portfolio

A responsive React + Vite portfolio website built from the supplied resume and the profile/project information provided in the chat.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Customize

- Edit `src/main.jsx` for text, projects, links and skills.
- Edit `src/styles.css` for colors, spacing and layout.
- Replace the placeholder LinkedIn/GitHub URLs with your actual profiles.
- The email shown is the one present in the supplied resume.

## Included

- Responsive single-page React portfolio
- Dark/light theme toggle
- Mobile navigation
- Hero, About, Skills, Projects, Current Focus and Contact sections
- No backend required
